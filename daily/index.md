# Daily Intelligence

Daily reports are the **Evidence / Signal** layer of Agent Intelligence.

Each report preserves newly published, high-value first-party updates with source metadata, technical details, interpretation, reading priority and original links. The daily archive is intentionally selective: days with no meaningful update may explicitly record that no important signal was found.

Use the sidebar to browse reports in reverse chronological order.

## Reading model

The complete daily report lives here. Chat notifications only surface the small number of items that deserve additional attention; the archive remains the canonical record.
