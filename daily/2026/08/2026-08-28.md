## Anthropic — Model Hardware Standard (MHS) Research Preview

- **Source:** Anthropic
- **Published:** 2026-08-27
- **Topics:** Agent Protocol, Physical Tool Runtime, MCP, Recovery
- **Priority:** ★★★★★
- **Original:** <https://www.anthropic.com/news/model-hardware-standard-research-preview>

### What changed

Anthropic 发布 Model Hardware Standard（MHS）研究预览，目标是为 AI Agent 操作物理设备提供统一规范。当前应用场景包括显微镜、液体处理设备、机械臂、量子计算激光系统等，并计划在 Research Preview 之后开源。

### Technical details

MHS 引入统一 Driver，通过标准 primitive 暴露设备操作，同时提供设备发现和 capability 描述。设备状态、操作能力、物理属性以及安全限制可以通过标准化描述提供给 Agent。

MHS 并不是替代 MCP 的 Agent ↔ Tool 上层协议，而更像位于 MCP 下面的 hardware abstraction：

```text
Agent Harness
    │
    ├── MCP
    ├── CLI
    └── Code / API
          │
          ▼
       MHS Driver
          │
          ▼
   Physical Device
```

MHS 还允许把设备重量、可调参数、安全限制等自然语言元数据纳入 Agent 可读取的设备描述。对于长时间或高速执行操作，Agent 可以预先生成多个 driver command 组成的代码，再交给 runtime 执行，而不是让每一步都经过模型在线推理。

Anthropic 公布的 QuEra 案例还涉及自动 failure recovery：Agent 使用 MHS 自动恢复量子计算机激光系统的锁定状态。

### Why it matters

MHS 把 capability abstraction 从软件工具继续向物理世界扩展。Agent 不需要直接拥有设备能力，而是通过标准化 capability layer 发现、理解和调用设备；这会进一步涉及 capability discovery、device manifest、permission、physical safety 和 runtime recovery。

**Worth reading:** 是，优先级 ★★★★★。

## Cursor — Start from scratch, without a repo

- **Source:** Cursor
- **Published:** 2026-08-27
- **Topics:** Coding Agent, Cloud Agent, Environment Lifecycle
- **Priority:** ★★★☆☆
- **Original:** <https://cursor.com/changelog/start-from-scratch>

### What changed

Cursor Cloud Agents 不再要求任务开始前必须已经存在 GitHub 或其他 SCM repository。用户可以从空白环境直接描述需求，由 Cloud Agent scaffold 项目，在后台创建 Origin repository，并在完成初始实现后再决定是否正式保存。

### Technical details

Cloud Agent lifecycle 从典型的：

```text
Existing Repo
   ↓
Provision Environment
   ↓
Agent Session
   ↓
Commit / PR
```

扩展为：

```text
Intent
   ↓
Ephemeral Agent Environment
   ↓
Agent scaffolds project
   ↓
Preview / Iterate
   ↓
Materialize as Repo
```

Cursor 同时提供 Cloud Agent 环境到浏览器的 port forwarding，可以直接访问 Agent 启动的服务并预览，再决定是否保存为 repository。

### Why it matters

Repository 从 Coding Agent 的严格前置条件，开始变成 Agent execution lifecycle 中可以被创建和 materialize 的对象。Cloud Coding Agent 因此进一步从 repository modification agent 向 software creation runtime 演进。

**Worth reading:** 可读，优先级 ★★★☆☆。
